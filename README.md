## 🎵 Music Download Feature

SPACE-MD now includes a YouTube music download command that allows users to download audio from YouTube videos directly in WhatsApp.

### Usage
- `!play <YouTube URL>` - Download audio from a YouTube video
- `!music <YouTube URL>` - Alias for the play command

### Features
- Audio-only download (high quality)
- Automatic conversion to MP3 format (128kbps)
- Duration limit: 10 minutes maximum
- Beautiful formatted responses
- Automatic cleanup of temporary files
